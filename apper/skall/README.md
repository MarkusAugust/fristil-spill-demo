# Skallet

Tre rammer side om side, én per utgave. Det er den eneste måten å se
påstanden til demoen på én skjerm: den samme saken, det samme skjemaet, det
samme designsystemet, tegnet av tre teknologier som ikke har noe til felles.

Skallet har ingen avhengigheter og ingen byggesteg. Det er med vilje: en side
som skal vise fram tre rammeverk kan ikke være reklame for et fjerde.
